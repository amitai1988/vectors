בכיתה

מתי שני וקטורים תלויים?

גררו את הראש של b. מתי הוא "כפולה" של a?
האם b כפולה של a?
תלויים לינארית אחד מהם הוא כפולה של השני: b = ka
בשרטוט: הם מקבילים (או שאחד מהם 0).

לא תלויים? ← בלתי תלויים.

זה בדיוק המצב משיעור 3: כל וקטור הוא צירוף שלהם, ומותר להשוות מקדמים.
למה גם וקטור האפס "תלוי" בכל וקטור? כי 0 = 0 · a — הוא כפולה של כל וקטור.
בכיתה

הגדרה כללית: צירוף שמתאפס

b = 3a3a − b = 0
העברנו אגף — וקיבלנו צירוף ששווה ל־ 0, עם מקדמים שאינם אפס.
תלות לינארית יש מקדמים, לא כולם אפס, כך ש־ k₁v₁ + … + kₙvₙ = 0
מתאפס רק כשכל המקדמים אפס? ← בלתי תלויים.
הכלי החשוב: a, b בלתי תלויים ו־ ka + tb = 0 ← k = t = 0
לדיון בכיתה
מה היה קורה אם היינו מוותרים בהגדרה על "לא כולם אפס"?

שלוש נקודות על ישר אחד

משפט A, B, C על ישר אחד ⇔ AC = kAB
גררו את C

מה k מספר?

1
0 < k < 1 — C בין A ל־ B
2
k > 1 — C אחרי B
3
k < 0 — C בצד השני של A

דוגמה

AK = ½a, AL = ¾a + ¼b, AM = a + ½b. האם K, L, M על ישר אחד?

KL = AL − AK = ¼a + ¼b KM = AM − AK = ½a + ½b KM = 2KL
כן! ואפילו יותר: L היא אמצע KM.
לבד

מציאת מקדמים

הגענו ל"צירוף = 0", ו־ a, b בלתי תלויים? כל מקדם = 0.

דוגמה 1

(k − 2)a + (t + 1)b = 0
a
k − 2 = 0 ← k = 2
b
t + 1 = 0 ← t = −1

דוגמה 2: מערכת משוואות

(k + t)a + (k − t − 4)b = 0
k + t = 0k − t − 4 = 02k − 4 = 0k = 2t = −2
שימו לב: קודם מסדרים — a פעם אחת ו־ b פעם אחת בכל צד — ורק אז משווים.
לבד

נקודה על ישר — סכום המקדמים 1

משפט P על הישר AB ⇔ OP = (1 − λ)OA + λOB
במילים: סכום המקדמים 1.

דוגמה

OP = ⅓OA + ⅔OB
1
סכום המקדמים 1 ← P על הישר AB.
2
λ = ⅔ ← AP = ⅔AB, ולכן AP : PB = 2 : 1.
לזכור: המקדם הגדול שייך לנקודה ש־ P קרובה אליה.
הוכחה קצרה: OP = OA + AP = OA + λAB = OA + λ(OB − OA) = (1 − λ)OA + λOB.

ארבע נקודות במישור אחד

משפט (במרחב) A, B, C, D במישור אחד ⇔ AD = kAB + tAC

AB = a, AD = b, AA' = c

האם A, B, C', D' במישור אחד?

AD' = b + cAC' = a + b + c = AB + AD'
כן ✓ (זה המלבן ה"אלכסוני" ABC'D')

האם A, C, B', D' במישור אחד?

b + c = k(a + b) + t(a + c)
a
k + t = 0
b
k = 1
c
t = 1
אבל אז k + t = 2, ולא 0 — סתירה. לא במישור אחד ✗

סיכום השיעור

  • שני וקטורים תלויים לינארית ⇔ אחד מהם כפולה של השני ⇔ הם מקבילים (או שאחד מהם 0).
  • הגדרה כללית: יש צירוף שמתאפס, עם מקדמים שלא כולם אפס.
  • אם a, b בלתי תלויים ו־ ka + tb = 0, אז k = t = 0.
  • במישור כל שלושה וקטורים תלויים. במרחב — שלושה וקטורים תלויים ⇔ הם במישור אחד.
  • A, B, C על ישר אחד ⇔ AC = kAB.
  • P על הישר AB ⇔ OP = (1 − λ)OA + λOB (סכום המקדמים 1).
  • A, B, C, D במישור אחד ⇔ AD = kAB + tAC.

עכשיו — לתרגול!
